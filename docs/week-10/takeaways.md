## 本周核心认知清单

- [ ] 有效单位成本 = 名义单位成本 ÷ 利用率——利用率是 Week 9 所有优化的分母
- [ ] 算力三条路：自建（CapEx）/ 长期预留（承诺型 OpEx）/ 按需（纯 OpEx）——买车 / 长租 / 打车
- [ ] 真实利用率：企业自建推理 20-40%，超大规模云 60-70%，特化推理云 70-85%
- [ ] 云厂商相对自建的核心优势不是卡更便宜，是多租户削峰填平彼此的峰谷
- [ ] 峰谷比的根子是人类作息，技术消灭不了，只能靠调度缓解
- [ ] 算力比电力更糟：电可以抽水蓄能，算力这一秒没人用就永久消失
- [ ] 定价阶梯：按需 $4.00 / 1年预留 $2.60 / 3年预留 $1.80 / 竞价 $1.20（每 GPU·小时）
- [ ] 预留 vs 按需盈亏平衡点：一天用满 10.8 小时（45% 时间）——按容量分层判断，不是整体判断
- [ ] 竞价实例的本质是云厂商把自己的利用率风险打折卖给你
- [ ] 训练能用竞价（有 Checkpoint 可恢复），在线推理不能——可恢复性本身就是议价能力
- [ ] Serverless GPU 的冷启动是数据搬运的物理下限，不是工程债：70GB 权重 vs CPU 函数几 MB
- [ ] 冷启动分解：拉镜像 + 对象存储→本地盘（56 秒 @10Gbps）+ 本地盘→显存 + 框架初始化 ≈ 30 秒-2 分钟
- [ ] 预热池破坏了"不用不计费"的承诺，供应商能做是因为多租户聚合——经济性来自规模不是技术
- [ ] Serverless GPU 吃的是常驻部署的长尾（批处理、微调、上百个低频小模型），不是在线推理
- [ ] GPU 调度不能超卖（显存是硬墙，失败模式是崩溃不是变慢），这给利用率设了天花板
- [ ] 碎片化在两个尺度重复出现：卡内 KV Cache 碎片（PagedAttention）vs 卡间集群碎片（装箱+整理）
- [ ] 切卡三法：MIG（硬件隔离，生产用）/ 时间片（无隔离）/ MPS（弱隔离）
- [ ] 异构木桶效应：分布式训练不能跨型号（AllReduce 同步），推理可以（副本独立）
- [ ] 老 GPU 不会消失，会从训练岗位转到推理岗位——这给残值托了底
- [ ] 弹性伸缩有效的前提是扩容耗时 < 流量爬坡时间，否则数学上无效，只能提前预热（= 提前付费）
- [ ] 全按需反而最贵：消除浪费 ≠ 降低成本，单价溢价 2.2 倍超过了省下的空闲 2.1 倍
- [ ] 分层定价把有效单价从 $3.72 压到 $2.33（−37%），不依赖任何新的推理技术
- [ ] 云厂商赚"利用率价差"（运营的钱），推理服务商赚"优化技术价差"（技术的钱）——两层在互相侵蚀
- [ ] 自研芯片的 ROI 在采购合同上不在芯片上——沃尔玛自有品牌可乐的逻辑
- [ ] GPU 云卖的是集群不是卡，万卡级可靠组网能力决定能接什么单
- [ ] Neocloud 的模式押注 GPU 残值坚挺（抵押融资），这是分析它的单一关键变量
- [ ] 调度软件与推理框架同一种位置：决定谁能赚钱，自己很难收费——技术重要性 ≠ 价值捕获能力
- [ ] 算力正在金融化：出现期限结构（预留）、风险定价（竞价）、抵押融资——电力市场走过同样的路
