## 本周核心认知清单

- [ ] 推理 vs 训练：训练是"建工厂"一次性投入，推理是"工厂运转"持续成本
- [ ] 推理算力需求是训练的 3-10 倍——推理成本正在超过训练成本
- [ ] 推理两大指标：延迟（TTFT，聊天敏感）vs 吞吐（总处理量，批处理敏感）
- [ ] 延迟和吞吐往往不可兼得——出租车 vs 公交车的权衡
- [ ] KV Cache 是推理内存核心——70B 模型 128K 上下文下 KV Cache（343GB）比模型参数还大
- [ ] 量化：BF16→INT8→INT4，精度换吞吐。INT8 是甜点区（损失<3%，省4倍）
- [ ] PTQ（训练后量化）vs QAT（量化感知训练）——JPEG 压缩类比
- [ ] PagedAttention：分页管理 KV Cache，消除内存碎片，吞吐提升 2-4 倍
- [ ] GQA：架构层面缩小 KV Cache 4-8 倍，现代模型标配
- [ ] 投机解码：小模型草稿大模型验证，延迟改善 2-3 倍且不损精度
- [ ] 蒸馏：大模型教小模型，成本降 10 倍，能力保 80%
- [ ] token 经济学：GPU $2/小时 → 100万 token 成本约 $5.5
- [ ] 推理成本 2 年降 10 倍——释放应用层需求
- [ ] 推理集群 vs 训练集群：性价比优先、分散部署靠近用户
- [ ] 推理时代赢家分散化：推理芯片、推理云服务、应用层受益
- [ ] 组合优化叠加效应：INT8+GQA+PagedAttention+投机解码 ≈ 吞吐 10-20 倍
