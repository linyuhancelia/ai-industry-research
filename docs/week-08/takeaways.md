## 本周核心认知清单

- [ ] 训练的本质：反复"猜下一个 token → 算错误 → 调参数"循环数万亿次
- [ ] 单块 GPU 训练 700B 模型需要约 300 年——必须万卡并行
- [ ] 数据并行（DP）：每卡持完整模型，各自算不同数据，每步 AllReduce 同步
- [ ] 张量并行（TP）：每层矩阵切开分到多卡，每个算子后都要同步（必须 NVLink）
- [ ] 流水线并行（PP）：不同层分到不同卡，有气泡浪费，但通信需求低
- [ ] 3D 并行组合：TP 放机器内（NVLink）、PP 放机器间、DP 放全集群
- [ ] 混合精度：BF16 前向/反向 + FP32 主参数存储和更新
- [ ] 梯度检查点：只保存部分层激活值，反向时重算——用 30% 时间换 60-70% 内存
- [ ] 数据质量 > 数据数量——精选 1.4T token 训练效果 > 全量 15T token
- [ ] 代码数据能提升逻辑推理——GPT-4 代码训练比例高达 25%
- [ ] 合成数据能补充但不能替代真实数据——模型崩塌限制了自我生成循环
- [ ] 预训练占 99% 计算量，但 SFT+对齐决定 90% 用户体验
- [ ] RLHF 三步走：偏好数据→奖励模型→PPO 强化学习
- [ ] DPO 一步到位：跳过奖励模型，直接从偏好数据优化（简单但上限受限）
- [ ] 万卡集群每天约 1 次 GPU 故障——Checkpoint 存档是训练能完成的前提
- [ ] GPT-4 级别模型训练总成本估计 $8000 万 - $1.5 亿
