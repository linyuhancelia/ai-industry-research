## 本周核心认知清单

- [x] 训练的本质：反复"猜下一个 token → 算错误 → 调参数"循环数万亿次
- [x] 单块 GPU 训练 700B 模型需要约 300 年——必须万卡并行
- [x] 数据并行（DP）：每卡持完整模型，各自算不同数据，每步 AllReduce 同步
- [x] 张量并行（TP）：每层矩阵切开分到多卡，每个算子后都要同步（必须 NVLink）
- [x] 流水线并行（PP）：不同层分到不同卡，有气泡浪费，但通信需求低
- [x] 3D 并行组合：TP 放机器内（NVLink）、PP 放机器间、DP 放全集群
- [x] 混合精度：BF16 前向/反向 + FP32 主参数存储和更新
- [x] 梯度检查点：只保存部分层激活值，反向时重算——用 30% 时间换 60-70% 内存
- [x] 数据质量 > 数据数量——精选 1.4T token 训练效果 > 全量 15T token
- [x] 代码数据能提升逻辑推理——GPT-4 代码训练比例高达 25%
- [x] 合成数据能补充但不能替代真实数据——模型崩塌限制了自我生成循环
- [x] 预训练占 99% 计算量，但 SFT+对齐决定 90% 用户体验
- [x] RLHF 三步走：偏好数据→奖励模型→PPO 强化学习
- [x] DPO 一步到位：跳过奖励模型，直接从偏好数据优化（简单但上限受限）
- [x] 万卡集群每天约 1 次 GPU 故障——Checkpoint 存档是训练能完成的前提
- [x] GPT-4 级别模型训练总成本估计 $8000 万 - $1.5 亿
- [x] 并行方式的本质是"切法"不同：TP 切矩阵内部、PP 切层间、DP 切数据——切得越细通信越频繁
- [x] RLHF 的核心优势是奖励模型可迭代，能探索出训练数据中没有的更好答案；DPO 天花板取决于已有偏好对

## 形成的判断框架

### 框架 17：并行方式的"切法"三分

分布式训练的三种并行本质是三种不同的"切法"：TP 切**矩阵内部**（层内并行）、PP 切**层与层之间**（层间并行）、DP 切**数据**（副本并行）。切得越细通信越频繁，必须用最快的互联。

### 框架 18：迭代优势 vs 静态天花板

简单方案（DPO）依赖既有数据，效果有静态天花板；复杂方案（RLHF）能随反馈数据持续迭代，天花板会随规模扩大不断上移。选择取决于当前规模下静态天花板是否已经足够。
